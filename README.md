# Maple Browser

Maple Browser is a simple, lightweight web browser by Team Celeste. It is designed around the familiar comfort of Safari while keeping the experience clean, fast, and uncomplicated.

Maple uses native platform technologies instead of Chromium, with a focus on a small, comfortable browsing experience.

## Features

- Lightweight web browsing
- Google as the default search engine
- Simple, familiar browser interface
- Tabbed browsing
- Bookmarks
- Browsing history
- Content blocking and ad blocking
- Redirect and pop-up blocking
- Siri and Shortcuts integration
- Native platform integration
- Minimal and uncluttered design
- Open source

Maple is intentionally focused on browsing rather than filling the browser with unnecessary features. There is no built-in AI and no Chromium dependency.

## Platforms

### iOS

- Minimum version: iOS 12.0
- SwiftUI-based interface
- WebKit-based browsing

### Android

- Minimum version: Android 5.1 (API 22)

## Philosophy

> Simple. Comfortable. Lightweight.

Maple is designed to feel familiar from the moment you open it. It aims to provide the convenience and comfort people expect from a modern browser without unnecessary complexity.
